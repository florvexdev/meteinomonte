Questo file contiene `message_id.txt`, l'id del messaggio Telegram che il bot
aggiorna in-place ad ogni ciclo (invece di inviarne uno nuovo ogni volta).
Viene creato/aggiornato automaticamente dallo script — non modificarlo a mano.
Se vuoi forzare l'invio di un nuovo messaggio (es. dopo una lunga pausa),
cancella semplicemente `message_id.txt`.
